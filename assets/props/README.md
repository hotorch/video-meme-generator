# Props

Non-person reference images for Genjutsu (a car, a product, an object to swap in), one folder per prop:
`assets/props/<slug>/<name>.png` (+ the Codex sidecar `.json`). Everything except this README is gitignored.

Make one with Codex when the user names an object but gives no image, e.g.
`memegen image gen <unit> --name tesla_black --prompt "black electric SUV, front three-quarter view, desert dirt road, no people"`,
then copy the chosen PNG here and send it as its own `<<<image_N>>>`.
